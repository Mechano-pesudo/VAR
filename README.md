# Fusion2FreeCAD — Project Website

Project page for **"Validity-Assured Regeneration of Parametric Solid Modeling"** (SIGGRAPH Asia).

## File Structure

```
├── index.html           # Main page
├── css/index.css        # Styles
├── js/index.js          # Scroll animations, copy button
├── assets/
│   ├── images/          # Put paper figures, teaser, result images here

└── .gitignore
```
